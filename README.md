# Alshaima Syed — Cybersecurity Portfolio

Static portfolio website prepared for GitHub Pages.

## Publish

1. Create a public GitHub repository named `alshaima-cybersecurity-portfolio`.
2. Upload all files from this folder to the root of the repository.
3. Open **Settings → Pages**.
4. Set **Source** to **Deploy from a branch**.
5. Select **main** and **/(root)**, then click **Save**.

The site will be available at:
`https://alshaima-cybersec.github.io/alshaima-cybersecurity-portfolio/`
